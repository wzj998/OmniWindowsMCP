# OmniWindowsMCP

## 中文

### 简介
OmniWindowsMCP 是一个面向 Windows 的 MCP（Model Context Protocol）示例项目，提供自动化相关的能力与技能集合，并基于 `pyautogui` 实现桌面操作与交互自动化。

### 特性
- 基于 `pyautogui` 的 Windows 自动化能力示例。
- 可扩展的技能与能力集合，便于在 MCP 生态中集成。
- 结构简单，适合作为学习与快速验证的起点。

### 快速开始

1. 克隆仓库
   ```bash
   git clone <your-repo-url>
   cd OmniWindowsMCP
   ```

2. 安装依赖
   ```bash
   pip install -r requirements.txt
   ```

3. 运行示例
   ```bash
   python OmniWindowsMCP.py
   ```

### 项目结构
- `OmniWindowsMCP.py`：主程序入口。
- `SubtitleWindow.py`：字幕窗口相关功能。
- `TestOmniWindowsMCP.py`：测试脚本。
- `requirements.txt`：依赖清单。

### 贡献
欢迎提交 Issue 或 Pull Request 来改进项目。

## English

### Overview
OmniWindowsMCP is a Windows-focused MCP (Model Context Protocol) sample project that provides automation-related capabilities and a set of skills, built on top of `pyautogui` for desktop interaction and automation.

### Features
- Windows automation examples powered by `pyautogui`.
- Extensible skill and capability set for MCP integrations.
- Simple structure, suitable for learning and quick validation.

### Quick Start

1. Clone the repo
   ```bash
   git clone <your-repo-url>
   cd OmniWindowsMCP
   ```

2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

3. Run the example
   ```bash
   python OmniWindowsMCP.py
   ```

### Project Structure
- `OmniWindowsMCP.py`: main entry.
- `SubtitleWindow.py`: subtitle window features.
- `TestOmniWindowsMCP.py`: test script.
- `requirements.txt`: dependencies.
